# Test plan: feature/fernly-helper

## Summary

Adds **Ask Fernly**, a fixed chat helper on every page (`HelperWidget` in `Layout`). The browser posts to `POST /api/helper/chat`; the API stand-in returns a reply and optional tool call (`search_plants`, `open_plant`, `add_to_cart`, `care_tip`); the widget runs the tool (navigate, filter catalog, or add to cart). Dev-only `window.__fernlyHelper` and `HELPER_SEED` support testing. Branch also adds a catalog k6 harness and helper Playwright project wiring.

Oracle: `docs/features/fernly-helper.md`, cart / sign-in / a11y rules in `docs/PRODUCT.md`, OpenAPI `HelperChatRequest` / `HelperChatResponse`. Diff: `origin/init...HEAD`.

**Approval needed before specialist handoff.** Reply `approved` / add label `plan-approved` (or request changes). Do not write or hand off tests until this plan is approved.
