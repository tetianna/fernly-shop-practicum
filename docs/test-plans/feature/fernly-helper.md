# Test plan: feature/fernly-helper

## Summary

Adds **Ask Fernly**, a fixed chat helper on every page (`HelperWidget` in `Layout`). The browser posts to `POST /api/helper/chat`; the API stand-in returns a reply and optional tool call (`search_plants`, `open_plant`, `add_to_cart`, `care_tip`); the widget runs the tool (navigate, filter catalog, or add to cart). Dev-only `window.__fernlyHelper` and `HELPER_SEED` support testing.

The same branch also fixes money and privacy behaviour that customers already rely on: free shipping at exactly **$50.00**, percent promos off **plants only**, expired promo refusal, author-only review delete, review average rounding, catalog `price-desc`, two-decimal price display, quantity at stock limit, browse catalog error vs empty, and several a11y labels/keyboard fixes. Package scripts add helper Playwright and catalog k6 harnesses.

Oracle: `docs/features/fernly-helper.md`, `docs/features/promo-codes.md`, `docs/features/plant-reviews.md`, cart / sign-in / money / a11y in `docs/PRODUCT.md`, OpenAPI `HelperChatRequest` / `HelperChatResponse`. Diff: `origin/init...HEAD`.
