# Test plan: feature/back-in-stock

## Summary

Browse plant cards warn when only a few are left, and an out-of-stock plant’s page lets anyone (no account) leave an email to be told when it is back. The API is `POST /api/plants/{plantId}/notify`. Emails must be full addresses; one sign-up per email per plant (case-insensitive); in-stock plants are refused. Expectations below are the documented ones: a failure against the app is a possible finding, not a reason to change the assertion. Shared promo-codes and harness files also appear on this branch against `origin/init`, but they are already covered by `docs/test-plans/feature/promo-codes.md` and its results — this plan covers the back-in-stock product surface only. This plan is not approved. Rows marked `assumed — ask` get no test until a human resolves them.
