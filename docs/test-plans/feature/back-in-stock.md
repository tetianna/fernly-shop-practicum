# Test plan: feature/back-in-stock

## Summary

Adds low-stock badges on plant cards and an email notify sign-up for out-of-stock plants: `POST /api/plants/{plantId}/notify`, `StockBadge` + plant-card slot, and `NotifyForm` + plant-page slot. No account required. Oracle: `docs/features/back-in-stock.md`, plus WCAG rules in `docs/PRODUCT.md`. Diff: `origin/main...HEAD`.

**Approval needed before specialist handoff.** Reply `approved` / add label `plan-approved` (or request changes).

## Notes / ask before coding tests

| Topic | Why |
| --- | --- |
| Exact invalid-email copy | Doc requires refusal of `a@b` / `name@` but does not fix the `detail` string. Tests assert refusal (4xx + no subscription); treat specific wording as **assumed — ask** if not stable in OpenAPI. |
| Duplicate message oracle | Doc fixes UI/API customer copy to **“You're already on the list”**; OpenAPI names rule `already_subscribed`. Prefer the doc string in assertions. |
| Stock 0 UI ownership | Card already has sold-out overlay “Out of stock”; low-stock badge must stay absent at 0 so both never appear together as “Only 0 left”. |
