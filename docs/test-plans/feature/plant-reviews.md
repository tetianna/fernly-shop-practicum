# Test plan: feature/plant-reviews

Customers can read and write reviews on a plant page. The change adds `GET`/`POST /api/plants/{plantId}/reviews` and `DELETE /api/reviews/{reviewId}`, plus plant-page Reviews UI (`ReviewList`, `ReviewForm`, `StarRatingInput`, `reviews` slot).
