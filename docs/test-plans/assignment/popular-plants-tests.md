# Test plan: assignment/popular-plants-tests

## Summary

`origin/init...HEAD` is empty: this tip matches `init`, which already ships **Popular right now** (`GET /api/popular`, `PopularList`, `plant-page/popular` slot, `docs/features/popular-plants.md`). Ranking is by units sold in the last 30 days (not order count), most first; ties by name A–Z; out-of-stock plants omitted; the plant on screen is left out of its own list.
